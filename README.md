# v-skills

Personal Claude Code marketplace. All skills are prefixed `v-`.

```bash
claude plugin marketplace add <path-or-github-repo>
claude plugin install productivity@v-skills
claude plugin install engineering@v-skills
claude plugin install finances@v-skills
```

| Plugin | Skills |
|---|---|
| `productivity` | `v-wiki-init`, `v-retro`, `v-grill` |
| `engineering` | `v-dotnet-as-java` |
| `finances` | _none yet_ |
